Harness command

You run npm run harness, the harness writes the module and the test, then it runs the tests.

npm run harness -- function "order total with tax and a percentage discount"
npm run harness -- function "add 2 numbers"

The first word is the command. The quoted text is the requirement. Add --overwrite when the files already exist.

The harness wrote these two modules:

  • workspace/src/add-2-numbers.js returns left + right.
  • workspace/src/order-total-tax-percentage.js applies the percentage discount, then the tax.

From Claude

Claude Code sends the command and the requirement to the harness. The harness generates the code.

cd /Users/sanjaysingh/Documents/ClaudeCode_CLI
claude

Inside the session:

/gen function add 2 numbers
/test add-2-numbers
  1. /gen calls the harness build tool.
  2. The harness writes workspace/src and workspace/test.
  3. The harness runs the tests and lint.
  4. Claude shows the file names and the result.

/test only runs the tests and reports them. It leaves the files as they are.
