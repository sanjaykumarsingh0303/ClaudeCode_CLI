# Practice notes MCP

This folder is a Claude Code CLI practice project. A local MCP server named `practice-notes` is declared in `.mcp.json`.

Use these tools when the user asks about the notebook:

- `add_note` to save a title and body
- `list_notes` to read everything
- `search_notes` to find a word
- `delete_note` to remove one note by id
- `update_note` to change a note's title and/or body by id

Notes are stored in `data/notes.json`. The resource `notes://all` is the same notebook as JSON. The prompt `summarize_notes` asks for a short summary.

Do not invent note ids. Read them from `list_notes` or `add_note` first.

# Fake coding harness

A second local MCP server, `fake-harness` (`harness/server.ts`), generates working code in `workspace/` (`workspace/src` for code, `workspace/test` for `node --test` tests).

- `build` writes the implementation itself from the command and the requirement. Use this when the user wants code generated.
- `generate` only writes an empty scaffold. `list_templates`, `run_tests`, and `lint` are still available.
- Keep the `// Generated by fake-harness` header.
- Slash commands: `/gen <command> <requirement>`, `/test [filter]`, `/auto <command> <requirement>`.
- From a terminal: `npm run harness -- <command> "<requirement>"`.
