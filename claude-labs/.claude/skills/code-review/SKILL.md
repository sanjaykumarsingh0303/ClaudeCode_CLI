# Code Review Skill

When reviewing code, follow these steps:

1. Inspect the project structure.
2. Review Python coding standards.
3. Identify potential security vulnerabilities.
4. Check exception handling.
5. Check input validation.
6. Identify performance issues.
7. Review unit test coverage.
8. Identify missing production-readiness features.

## Output format

Provide findings using these categories:

- Critical
- High
- Medium
- Low

For each finding, explain:
- File and location
- Problem
- Potential impact
- Recommended fix

Do not modify files unless the user explicitly requests it.
